# legacy

Old code kept for reference.  **Not on the project path and not maintained.**
Many files are encoded in Shift-JIS and use functions removed from recent MATLAB
(`aviread`, `avifile`, `blkproc`, `movie`, ...).

| Folder | Content |
|---|---|
| `2019before/` | practice scripts of the CQ book "Image and Video Signal Processing with MATLAB" (2006–2008) |
| `work/` | demos from 2006 (video I/O, block DCT, 5/3 and 9/7 lifting, ...) |
| `Appendix/` | exercises of 2012–2015 (`practice_a_*`) and figure scripts (`draw_*`) |
| `msip-nsolt/+msip/` | NSOLT deep-learning layers formerly in `+msip`; the samples now use `saivdr.dcnn.*` of SaivDr |

The current sample codes are in `scripts/` and the helpers in `code/matlab/`.
